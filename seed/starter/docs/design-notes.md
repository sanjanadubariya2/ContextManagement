# Frontend design notes

## Layout
- Centered card on /login, max width 24rem, Tailwind `shadow-md rounded-xl`.
- Header shows the user's email and a logout button once logged in.

## Forms
- Labels above inputs; the submit button is disabled while a request is in flight.
- Validation messages appear under the field they belong to.

## Colors
- Primary: indigo-600. Errors: red-600. Neutral text: slate-700.
